# Zgadnij Słowo

**Zgadnij Słowo** to gra słowna, w której celem jest odgadnięcie ukrytego hasła poprzez wybieranie liter z klawiatury widocznej na ekranie.

## Funkcjonalności
- Losowanie słowa z dostępnej bazy haseł.
- Interaktywna klawiatura z polskimi znakami.
- Oznaczanie poprawnie i błędnie wybranych liter.
- Każda błędna litera odbiera jedno życie.
- Komunikaty o wygranej lub przegranej.
- Efekt konfetti wyświetlany po wygranej.
